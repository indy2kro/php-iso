# Fixtures

Small ISO images used by the tests. The older images (`test.iso`, `subdir.iso`, ...) were created by hand; the four
images below are generated by `build-fixtures.sh` (Docker, `debian:stable-slim`, `xorriso` 1.5.6 / `genisoimage`).
Run `fixtures/build-fixtures.sh` to regenerate them (`--inside` runs the build directly on a host that already has
the tools). Each image is about 360 KB because the tools pad the output.

| File | Purpose | Command |
|------|---------|---------|
| `rockridge.iso` | Rock Ridge (PX/TF/NM/SL), a symlink, a 214 character file name whose SUSP entries overflow the directory record (CE continuation area), a 5 level deep directory tree | `xorriso -as mkisofs -R -V ROCKRIDGE -o rockridge.iso <dir>` |
| `iso1999.iso` | ISO 9660:1999 Enhanced Volume Descriptor (type 2, version 2) without Joliet, long mixed case names | `genisoimage -iso-level 4 -V ISO1999 -o iso1999.iso <dir>` |
| `joliet_cjk.iso` | Joliet with Chinese/Japanese volume id, directory and file names | `genisoimage -J -joliet-long -input-charset utf-8 -V 'ボリューム中文' -o joliet_cjk.iso <dir>` |
| `no_extension.iso` | Plain ISO 9660 level 1, files without an extension (`README`, `LICENSE`) | `genisoimage -iso-level 1 -V NOEXT -o no_extension.iso <dir>` |

## Content

`rockridge.iso` (volume id `ROCKRIDGE`)

* `/hello.txt` (17 bytes), `/link_to_hello` symlink to `hello.txt` (size 0)
* `/long_name_` x21 + `.txt` (214 characters, 5 bytes)
* `/dir1/dir2/dir3/dir4/dir5/deep.txt` (5 bytes)

`iso1999.iso` (volume id `ISO1999`)

* `/a_rather_long_file_name_for_level_four.txt` (32 bytes), `/subdir/nested.dat` (7 bytes)
* Volume descriptors: PVD, then an EVD (type 2, version 2, no Joliet escape sequences), then the terminator.

`joliet_cjk.iso` (Joliet volume id `ボリューム中文`; the PVD volume id holds the raw UTF-8 bytes of the same text,
which is not strictly valid ACHARS but is what genisoimage writes)

* `/中文文件.txt` (8 bytes), `/日本語ファイル.txt` (9 bytes)
* `/ディレクトリ/ネスト.txt` (7 bytes)
* The primary tree uses mangled names (`_____000.TXT;1`, ...), the Joliet tree has the real names.

`no_extension.iso` (volume id `NOEXT`)

* `README.` (7 bytes), `LICENSE.` (13 bytes), `DATA.TXT` (5 bytes); level 1 names are stored as `README.;1`.
* A `;2` version file could not be produced: neither genisoimage nor xorriso can write explicit version numbers.
